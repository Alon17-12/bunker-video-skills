# פרומפט התיקונים — החוזה השני בין הבונקר לסוכן

הלקוח (ובסבב צוות — הצוות) כותב הערות בלשונית «תיקונים» של המסירה: כרטיס לכל סרטון, הערה בלחיצה על הנגן,
הזמן נשמר לבד. «העתק פרומפט» מוציא את כל ההערות **בדיוק בפורמט הזה**:

```
# תיקונים — בונקר אקספרס
תוכנית: <show> · סשן: <YYYY-MM-DD> · סבב: <לקוח|צוות> <N>

## הפרק השלם
- 03:12 — <הערה>
- כללי — <הערה על כל הסרטון>

## ריל 02 — <כותרת הריל>
- 0:24 — <הערה>
```

- **כותרת סרטון:** `## הפרק השלם`, או `## ריל NN — <כותרת>` (NN = מספר הריל ב-`רילס/רילס.json`).
- **הערה:** `- M:SS — טקסט`, `- H:MM:SS — טקסט`, `- 0:24.5 — טקסט`, או `- כללי — טקסט` (בלי זמן). המפריד: `—`, `–` או `-`.
- **הערה בכמה שורות:** שורה שלא מתחילה ב-`-` ממשיכה את ההערה שמעליה.
- **אסור לאבד:** שורת `-` שלא נקראת כהערה, או כותרת `##` שאינה «הפרק השלם» / «ריל NN», עוצרות את הקריאה עם השורה עצמה —
  אף הערה לא נעלמת בשקט. «העתק פרומפט» בבונקר חייב לייצר בדיוק את זה.
- **השעון:** הזמן בקובץ שנמסר. בריל — מתחילת הריל (= השעון של `rN.json`). בפרק — מתחילת הפרק המיוצא;
  `+ trim_in` מ-`פרק/פרויקט.json` נותן את שעון «מקור».

**אצל הסוכן:** שומרים את הפרומפט כ-`תיקונים/<סבב>.md` ומריצים
`$PY -m bsession corrections "<session>" "תיקונים/<סבב>.md"` → רשימת עבודה: לכל הערה הסרטון, הזמן, זמן «מקור» והמילים
שנאמרו שם (נשמר ב-`תיקונים/<סבב>.json`). משם — `references/corrections.md`.

**שינוי בפורמט** = שורת `פורמט: 2` מתחת לכותרת, והקורא (`bsession/corrections.py`) מתעדכן באותו סבב.
