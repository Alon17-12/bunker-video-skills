# תיקונים — צוות ולקוח

**מאיפה הם מגיעים:** לשונית «תיקונים» במסירה בבונקר — הערה בלחיצה על הנגן בכל סרטון, ו«העתק פרומפט» מוציא את כולן
בפורמט של `references/corrections-format.md`. הערות שאלון כותב בצ'אט בחופשי — אותו דבר, רק בלי הקובץ.

## השלבים
1. שומרים את הפרומפט כ-`תיקונים/<סבב>.md` (או את הצ'אט כמו שנכתב).
2. `$PY -m bsession corrections "<session>" "תיקונים/<סבב>.md"` → רשימת עבודה: לכל הערה הסרטון, הזמן, זמן «מקור», המילים שנאמרו.
3. **הערה שלא ברור לאיזה סרטון או רגע היא שייכת — חוזרת לאלון כשאלה.** לא מנחשים.
4. **מחוץ לסבב** (רגע אחר, ריל חדש) — לא נערך עכשיו; רשימה נפרדת לאלון. ללקוח יש סבב אחד.
5. **ביצוע — כל ההערות של סרטון בבת אחת:**
   - **מילה בכתובית** → `work/fixes.json` לפי זמן «מקור» → `build_cuts.py`.
   - **ניתוב / תגובה / מסך משולב / זום / תווית** → `public/plans.json` (עיגון למילים).
   - **חיתוך** (להוסיף/להוריד משפט, הוק) → `work/edl_rN.sh` → `build_cuts.py`; בודקים שהעיגונים ב-`plans.json` עדיין נמצאים.
   - **פרק** — התחלה/סוף, תיקון ניתוב, לוגו, כרטיס שם → `build_session_episode.py` בשם גרסה חדש.
6. `dump.ts` נקי → סטילס של כל רגע שתוקן → `export_capcut.ts` → `render_gfx.mjs` → `capcut_reels.py` בשם גרסה חדש
   (`… v2`) — **לעולם לא מעל פרויקט שאלון ערך ידנית.**
7. מתחת לכל הערה בקובץ הסבב: מה נעשה (`ריל 02 0:24 — «קפסולות» → תוקן ב-v2`). אומרים לאלון אילו פרויקטים חדשים.
8. אחרי אישור הצוות וייצוא: `$PY -m bsession deliver "<session>"`.
