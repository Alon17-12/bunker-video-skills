# תבנית — style-rules.md (שכבה 2, לכל סרטון)

כל שורה = הוראה שאפשר לבצע בקאפקאט. מספר → `[נמדד]`; מראה → `[נצפה]`; צליל → `[נשמע]`; דעה → `[הסקה]`.

```

## CUTTING
- קאט כל <avg_shot_s>s בממוצע (חציון <median>), אף שוט לא עובר <longest>s   [נמדד]
- <cuts_per_minute> חיתוכים לדקה; בהוק: <hook.cuts> חיתוכים ב-3 שניות         [נמדד]
- <האם הקצב משתנה — פתיח צפוף ואז הרגעה / קבוע>                             [נמדד]

## SHOTS
- חלוקת קאדרים: <framing_counts כאחוזים>                                     [נמדד]
- תנועה: <רוב השוטים static/slight/...>; <תנועה חוזרת שנצפתה>                [נמדד]+[נצפה]
- <מה השוט הארוך ביותר מכיל ולמה הוא מחזיק>                                  [נצפה]+[הסקה]

## CAPTIONS
- <changes_per_minute> החלפות לדקה; ~<מילים> מילים לכרטיס                     [נמדד]+[נצפה]
- מיקום <תחתון/מרכז>, <צבע>, <stroke/צל>, <משקל>, <גדול/קטן ביחס לפריים>      [נצפה]
- הדגשה: <צבע/גודל>, כל ~<N> שניות                                          [נצפה]
- יחס לדיבור: <מובילה/יושבת/מפגרת>                                          [נצפה]

## MUSIC
- <bpm> BPM ±3 / "אין ביט מחזורי — מונע-דיבור"                              [נמדד]
- מצע <bed_db> dB מתחת לדיבור                                                [נמדד]
- <ז'אנר, תחושה, כניסה/יציאה>                                                [נשמע]

## SFX
- <hits_per_minute> היטים לדקה; <share> מהחיתוכים מקבלים היט                 [נמדד]
- <סוגי צלילים אם זוהו>                                                       [נשמע]

## SPEECH
- <wpm> מילים לדקה; <pauses> הפסקות מעל 0.8s; הארוכה: <longest_pause>        [נמדד]

## STRUCTURE
- הוק: <מה נאמר / נראה / כתוב>                                               [נצפה]
- ביטים: <רשימה עם זמנים>                                                     [נצפה]
- CTA: <צורה ומיקום>                                                          [נצפה]
- קהל ורמת מודעות: <...>                                                      [הסקה]
```
